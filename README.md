# 🍽️ Cravora – Discover. Crave. Enjoy.

Cravora is a modern and elegant restaurant website designed to showcase delicious food, highlight special offers, and provide visitors with an enjoyable browsing experience.

## ✨ Features

- Modern and elegant restaurant design
- Responsive layout for different screen sizes
- Interactive navigation bar
- Light and dark mode
- Food categories section
- Bestselling dishes showcase
- Special offers section
- Customer testimonials
- Newsletter subscription interface
- Smooth scrolling and interactive elements

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS

## 📸 Website Sections

- Home
- Categories
- Bestsellers
- Special Offers
- About
- Testimonials
- Newsletter
- Footer
